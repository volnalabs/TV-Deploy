# Changelog

Все заметные изменения EasyTizen. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Раздел версии целиком попадает в описание релиза на GitHub.

## [0.9.0] — 2026-11-14

Первый выпуск под названием **EasyTizen** (раньше — TV Deploy) и первая версия для Android.

> [!IMPORTANT]
> Это предварительный выпуск. Автоматические тесты пройдены, но установка на **физический телевизор Samsung** и работа на **реальном Android-устройстве** ещё не подтверждены — см. «Известные ограничения». Версия 1.0.0 выйдет после такой проверки.

### Новое

- **Приложение для Android.** Самостоятельный установщик: поиск телевизора, подключение, получение DUID, выпуск сертификата Samsung, проверка, подписание и установка `.wgt` прямо с телефона — без компьютера, Tizen SDK и Termux.
- **Встроенный движок** (Android и, по выбору, компьютер): собственная реализация протокола SDB, подписание WGT (XML-DSig) и выпуск сертификатов через Samsung CA. Tizen SDK для него не нужен.
- **Установка Tizen SDK с прогрессом:** этапы и счётчик пакетов, отмена всего дерева процессов, продолжение прерванной установки, выбор папки и проверка свободного места до загрузки.
- **Менеджер сертификатов:** создание для одного или нескольких телевизоров, импорт готовой пары `author.p12` + `distributor.p12`, срок действия, удаление.
- **Менеджер телевизоров:** сохранённые устройства, переименование, копирование DUID, дата последнего подключения.
- **История установок** и **отчёт диагностики** (без паролей и ключей) с копированием и сохранением в файл.
- **Проверка обновлений** EasyTizen при запуске с прямой ссылкой на установщик для вашей платформы.
- **Мастер первого запуска** и встроенная инструкция по режиму разработчика с подставленным адресом для Host PC IP.
- Установка уже подписанного пакета без переподписания; удаление старой копии приложения с телевизора при конфликте автора (встроенный движок).
- Новый интерфейс: боковая и нижняя навигация, пошаговый прогресс установки, уведомления, пустые состояния, светлая/тёмная/системная темы, русский и английский языки.

### Изменено

- Продукт переименован в EasyTizen: новое имя, значок, идентификатор `io.github.volnalabs.easytizen`. Настройки, сохранённые телевизоры и профили сертификатов TV Deploy переносятся автоматически при первом запуске; Tizen SDK и его хранилище ключей не затрагиваются.
- Профиль сертификата может покрывать несколько телевизоров (несколько DUID).
- Файлы релиза получили постоянные имена: `EasyTizen-Android.apk`, `EasyTizen-Windows-x64-Setup.exe`, `EasyTizen-macOS-ARM64.dmg`, `EasyTizen-macOS-Intel.dmg`, `EasyTizen-Linux-x64.AppImage`, `EasyTizen-Linux-x64.deb`.

### Исправлено

- Отмена установки SDK останавливала только оболочку установщика, а загрузки продолжались в фоне.
- Рабочие копии подписанных пакетов не удалялись после установки и при сбоях.
- Ошибки установки показывались кодом без объяснения; теперь — понятный текст и подробности телевизора.
- Прерванное создание сертификата после выпуска сертификата автора приходилось начинать заново.

### Известные ограничения

- **Не проверено на оборудовании:** подключение, получение DUID, вход в Samsung Account, выпуск сертификата и установка проверены автоматическими тестами на эмуляторе телевизора и локальной замене Samsung CA, но не на физическом телевизоре и не на реальном телефоне.
- **Встроенный движок — экспериментальный.** Его подписи проверяются независимым `xmlsec1`, протокол сверен с официальным `sdb` 4.2.36, но приём пакета настоящим телевизором предстоит подтвердить. На компьютере по умолчанию используются официальные инструменты Samsung.
- **Android:** вход в Samsung проходит через браузер с возвратом на `localhost`; на прошивках с агрессивной «заморозкой» фоновых приложений после входа нужно вручную вернуться в EasyTizen. Сертификаты нельзя перенести между встроенным движком и Tizen SDK без импорта файлов `.p12`.
- **Пароль сертификата** во встроенном движке запрашивается один раз за запуск приложения и не сохраняется.
- **macOS:** установщику Tizen SDK нужен Bash 4+ (`brew install bash`).
- Обновление EasyTizen — это проверка новой версии и ссылка на установщик; автоматической тихой установки нет.
- Проверка подписи выбранного файла до установки — структурная; окончательное решение принимает телевизор.

## [0.1.0] — 2026-11-13

Публичная предварительная версия под названием TV Deploy: настольное приложение (Windows, macOS, Linux) на официальных инструментах Samsung — подготовка Tizen SDK, поиск и подключение телевизора, DUID, создание сертификата, проверка, подписание и установка WGT.
